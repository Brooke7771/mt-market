# mt-market

Ежедневные цены Маркетплейса Majestic RP (официальное API) для программы Majestic Tools.
Данные собираются раз в сутки (GitHub Actions, `collect.py`) и лежат в релизе `data`:

- `index.json` - время сбора и дата данных по каждой категории/серверу;
- `{категория}.json.gz` - статистика за 30 дней по всем серверам;
- `hist_{категория}_{сервер}.json.gz` - снимки по дням (до 35 дней).

Ключ API хранится только в секрете репозитория `MAJESTIC_API_KEY`.
